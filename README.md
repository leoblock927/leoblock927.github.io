# Leo Block — Portfolio

Personal portfolio: wire harness design and battery electronics for Longhorn Racing Solar, ECE at UT Austin.

Served with GitHub Pages from the `main` branch.

- `index.html`: home page (intro, project cards, experience, contact)
- `<project>/index.html`: one page per project (`smb`, `data-acquisition-harness`, `supplemental-battery`, `vehicle-harness-2027`, `integra`)
- `assets/site.css`, `assets/site.js`: shared styles and scripts
- `assets/img/`: project photos
